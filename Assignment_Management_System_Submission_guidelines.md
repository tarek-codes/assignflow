## 1. What to Submit

### Git Repository Link
Submit a GitHub or GitLab repository link containing the complete source code.

### Complete Project Code
Include in the repository:
- Frontend (Next.js/React/TypeScript)
- Backend/API (ASP.NET Core Web API)
- Database migration/seed files
- Unit tests

### Database Files
- EF Core migration files
- Seed/sample data
- Any database script or backup file needed for setup
- The evaluator should be able to set up the database using only the provided files/instructions — no manual table creation.

### README.md
Must include:
- Project overview
- Main features
- Technology stack
- Project structure
- Setup instructions (backend + frontend)
- Database setup instructions
- Instructions for running the frontend and backend locally
- Instructions for running the tests
- Assumptions made where requirements weren't explicit
- Known limitations

### Demo Credentials
Provide working login credentials for all three roles:

| Role | Email | Password |
|------|-------|----------|
| Admin | `admin@example.com` | `Password123!` |
| Teacher | `teacher@example.com` | `Password123!` |
| Student | `student@example.com` | `Password123!` |

### Environment Configuration
- Do **not** commit real passwords, API keys, or other secrets.
- Include an `.env.example` (frontend) and `appsettings.Example.json` or equivalent (backend) listing all required environment variables.

### Easy Local Setup
README must give clear, complete instructions so the project can be run locally without extra guesswork.

## 3. Final Checklist Before Submitting

- [ ] Repository link is accessible
- [ ] Frontend and backend are both included
- [ ] Database can be created using the provided files/instructions
- [ ] Demo accounts for all three roles (Admin, Teacher, Student) are available and working
- [ ] README explains how to run the project and its tests
- [ ] Role-based access is enforced by the backend API
- [ ] Important business rules are implemented and tested
- [ ] No real secrets or credentials are committed to the repository
- [ ] PDF submissions are viewable in-browser for teachers, with a download option
- [ ] DOCX submissions are downloadable for teachers
